# 💧 深空当铺 · 净水器核心计算器

《深空当铺》玩家自制的**净水器全能计算器**。根据游戏内 `MachinePurifier` 净水器的底层净化公式，实时推算单晚最大净水量、目标纯度与杂质残留，帮你规划"一晚上倒多少水才能稳出优质水 / 纯水"。

🔗 **在线使用**：https://beooto.github.io/water_purifier_calculator/

---

## ✨ 功能特性

- **⚙️ 机器参数配置**：自由调整性能加成 (Performance)、质量加成 (Quality)、效率加成 (Efficiency)，自动显示纯度上限与每日耗电
- **🎯 最大安全水量反推**：给定输入水质与目标水质，算出"一晚上必定达标"的最大装水量，一键填入
- **🔬 单晚净化模拟**：模拟当前水量睡一觉后的最终纯度、剩余杂质与今晚实际清理量
- **📅 多晚净化推演**：逐晚重算污秽系数，预测第几晚能达到目标水质
- **🧪 污染物梯队清理**：按游戏实际清理顺序（普通杂质 → 矿物质 → 重金属 → 化学污染物）模拟各成分残留
- **📌 公式速查**：内置核心计算公式备忘

## 🧮 核心公式

| 项目 | 公式 |
| --- | --- |
| 基础清理预算 | `min(容器总液量, 10L) × 3 mL/L + 25 mL`（10L 及以上固定 55 mL） |
| 最终清理额度 | `基础清理预算 × (污秽系数 + 性能加成%) × 1.25` |
| 纯度上限 | 由质量加成档位决定：0% → 99%、+15% → 99.15%、+25% → 99.35%、+50% → 99.65%、+75% → 99.8%、+100% → 99.9%、+200% → 100% |

**水质等级**：

| 纯度 | 等级 |
| --- | --- |
| ≥ 99.9% | 纯水 (Pure) |
| ≥ 99.0% | 优质水 (High-Quality) |
| ≥ 98.0% | 基础水 (Base) |
| ≥ 96.0% | 幽灵水 (Ghost) |
| ≥ 90.0% | 铁锈水 (Rust) |
| < 90.0% | 阴沟水 (Gutterflow) |

## 🚀 本地运行

纯前端静态页面，无需安装任何依赖：

1. 下载或克隆本仓库
   ```bash
   git clone https://github.com/beooto/water_purifier_calculator.git
   ```
2. 直接用浏览器打开 `index.html` 即可

> 页面样式通过 CDN 加载 [Tailwind CSS](https://tailwindcss.com/)，首次打开需要联网。
