# 💧 深空当铺 · 净水器计算器

《深空当铺》玩家自制的**净水器计算器**。根据游戏内 `MachinePurifier` 净水器的净化公式，帮你规划"一晚上倒多少水、倒多纯的水才能稳出优质水 / 纯水"。

🔗 **在线使用**：https://beooto.github.io/water_purifier_calculator/

---

## ✨ 功能特性

左侧设置参数，右侧切换三个场景，当前场景用不到的参数会自动置灰：

| 场景 | 已知 | 求 |
| --- | --- | --- |
| 🔬 净化模拟 | 性能、输入纯度、水量、目标纯度 | 明早纯度、剩余杂质、第几晚达标 |
| 🎯 最大水量 | 性能、输入纯度、目标纯度 | 一晚必定达标的最大装水量 |
| 🧮 最低入水纯度 | 性能、水量、目标纯度 | 输入水至少要多纯才能一晚达标 |

- 场景结果可一键带入「净化模拟」验证
- 参数和当前场景自动保存在浏览器本地，下次打开自动恢复

## 🧮 核心公式

| 项目 | 公式 |
| --- | --- |
| 基础清理额度 | `min(水量, 10L) × 3 mL/L + 25 mL`（10L 及以上固定 55 mL） |
| 今晚清理额度 | `基础清理额度 × (污秽系数 + 性能加成%) × 1.25` |

> 本计算器不考虑质量加成带来的纯度上限，默认机器已有足够的质量加成。

**水质等级**：

| 纯度 | 等级 |
| --- | --- |
| ≥ 99.9% | 纯水 (Pure) |
| ≥ 99.0% | 优质水 (High-Quality) |
| ≥ 98.0% | 基础水 (Base) |
| ≥ 96.0% | 幽灵水 (Ghost) |
| ≥ 90.0% | 铁锈水 (Rust) |
| < 90.0% | 阴沟水 (Gutterflow) |
